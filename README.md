# MabatID

A step-by-step path from baseline documents to primary Philippine government IDs.
Next.js (App Router), React, Tailwind CSS, shadcn on Base UI, and React Flow for the skill tree.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Other scripts: `npm run build`, `npm run start`, `npm run lint`.

Accounts and progress are stored in this browser (localStorage) until the MabatID server is connected.
